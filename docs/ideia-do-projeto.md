# Estuda+ - Identidade do projeto

## Frase do projeto

O Estuda+ é uma solução para estudantes que permite organizar a vida acadêmica através de um painel simples com faltas, lembretes e acompanhamento de estágio.

## Funcionalidades previstas

1. Acompanhar faltas por disciplina;
2. Mostrar o percentual de faltas utilizado;
3. Criar lembretes pessoais;
4. Marcar lembretes como concluídos;
5. Registrar dias e horas de estágio;
6. Exibir o progresso do estágio;
7. Futuramente, disponibilizar um mural de oportunidades acadêmicas e profissionais.

## Escopo do MVP

Para a primeira entrega, o projeto prioriza o dashboard, o controle de faltas, os lembretes e o acompanhamento do estágio. O mural de oportunidades ficará para uma próxima etapa, evitando que a primeira versão fique grande demais.
